# Super Admin Color Palette

## Overview

The Super Admin dashboard should convey **authority, trust, professionalism, and clarity**. The design should follow a modern SaaS aesthetic with clean layouts, subtle elevations, and excellent readability.

The recommended palette uses **Indigo** as the primary brand color, supported by neutral Slate tones and semantic status colors.

# Design Principles

The Super Admin interface should follow these principles:

- Modern SaaS-inspired design
- Clean and uncluttered layouts
- Strong visual hierarchy
- Generous whitespace
- Rounded corners (12–16px)
- Soft shadows instead of heavy borders
- Minimal use of bright colors
- Semantic colors reserved for status indicators
- Fully responsive layout
- Consistent 8-point spacing system

---

# UI Inspiration

The overall design language should resemble modern SaaS platforms such as:

- Linear
- Vercel Dashboard
- Stripe Dashboard
- Clerk
- GitHub
- Notion

The goal is to create a premium, professional interface that feels modern, intuitive, and scalable as additional roles and modules are introduced.
